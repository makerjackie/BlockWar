# BlockWar 演示文稿

这是一套为 BlockWar（方块战争）游戏设计的优雅 HTML 幻灯片，适合视频演示、项目介绍和推广使用。

## 📁 文件列表

- `index.html` - 幻灯片导航页面（推荐从这里开始）
- `slide-01-cover.html` - 封面页
- `slide-02-intro.html` - 游戏介绍
- `slide-03-features.html` - 核心功能
- `slide-04-highlights.html` - 特色亮点
- `slide-05-tech.html` - 技术栈
- `slide-06-opensource.html` - 开源理念
- `slide-07-cta.html` - 行动号召
- `slide-08-end.html` - 结束页

## 🎨 设计特色

- **视觉风格**：采用 BlockWar 游戏的深色主题（#07080a 背景）
- **配色方案**：标志性的黄色强调色（#f5c542）+ 白色文字（#f4f4f5）
- **设计元素**：方块网格背景、硬边框阴影、方块装饰元素
- **尺寸规格**：1920×1080（标准 Full HD），适合录屏和投影

## 🚀 使用方法

### 方法一：浏览器直接打开（推荐）

1. 双击 `index.html` 在浏览器中打开导航页
2. 点击任意幻灯片卡片查看对应页面
3. 按 F11 进入全屏模式获得最佳演示效果

### 方法二：单独打开幻灯片

直接双击任意 `slide-XX-xxx.html` 文件在浏览器中打开。

### 方法三：本地服务器（可选）

如果需要更好的预览体验，可以使用本地服务器：

```bash
# 使用 Python
python3 -m http.server 8000

# 或使用 Node.js
npx serve

# 然后访问 http://localhost:8000
```

## 🎬 视频录制建议

1. **分辨率设置**：录屏软件设置为 1920×1080
2. **浏览器全屏**：按 F11 进入全屏模式，隐藏浏览器工具栏
3. **切换方式**：
   - 在导航页点击切换（适合快速预览）
   - 直接打开各个 HTML 文件（适合逐页录制）
4. **停留时间**：建议每页停留 5-10 秒，根据内容调整

## 🔧 自定义修改

所有幻灯片都是独立的 HTML 文件，包含内联 CSS 样式，可以直接编辑：

1. **修改文字内容**：在 HTML 的 `<body>` 部分直接修改
2. **调整颜色**：在 `<style>` 部分修改 CSS 变量
3. **更换图片**：替换 `blockwar-pc.png` 和 `blockwar-mobile.png`

### 主要颜色变量

```css
background: #07080a;      /* 深色背景 */
color: #f4f4f5;           /* 主文字颜色 */
accent: #f5c542;          /* 黄色强调色 */
muted: #a1a1aa;           /* 次要文字颜色 */
panel: #101216;           /* 卡片背景 */
```
